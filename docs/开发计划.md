## 1. 已锁定的技术决策

| 决策点 | 结论 | 理由 |
| --- | --- | --- |
| 前端框架 | Vite 5 + React 18 + TypeScript（strict） | 轻量快速；类型安全受工程宪法约束（禁 `any`/`as any`/`@ts-ignore`） |
| 路由 | **不引入 react-router**，App 内用视图状态切换（登录页 / 主壳 4 Tab + 记录弹层） | 移动 App 式单页交互，减少部署与路由回退复杂度 |
| UI 方案 | 纯手写 CSS 设计令牌（从原型图 1:1 提取），无组件库 | 原型已有完整视觉系统；避免样式被组件库带偏 |
| 图标/字体 | FontAwesome 6 CDN + ZCOOL KuaiLe / Noto Sans SC / DM Mono（Google Fonts） | 与原型、设计规范一致；禁 emoji 图标 |
| 后端 | CloudBase BaaS，前端 SDK 直连（`@cloudbase/js-sdk`），**不用云函数** | PRD 无服务端密钥需求；认证/数据库/AI 均有 Web SDK 直连能力 |
| 认证 | 内置用户名密码（`usernamePassword` provider），`auth.getSession()` 管理会话，persistence=local | PRD 3.1；微信登录为 P2 不做 |
| 数据库 | 文档型数据库：`profiles` / `food_records` / `dishes` 三个集合，行级安全规则 | 环境 RuntimeMode=nosql，PG 不可用 |
| AI | **云函数 `ai-proxy`（Node.js Event 函数）中转**：前端 `callFunction` → 函数内 `@cloudbase/node-sdk` 的 `ai.createModel("cloudbase")` + `generateText`，`model: "hy3"`，返回结构化 JSON 食谱卡 | 小程序成长计划赠送额度**仅限小程序 SDK 与云函数消耗**（控制台横幅明确），Web 浏览器直连无法使用；用户已开通成长计划，hy3 有免费额度（生图模型 HY-Image-3.0-Plus 10 万次额度留作 P2 菜品封面） |
| 部署 | 本地 `vite build` → `manageApps(deployApp)` 独立子域名（新项目首部署禁止 manageHosting） | CloudBase 技能工程宪法 |
| AI 降级 | 预检不通过时，"问 AI"页自动降级为菜库搜索 + "AI 暂不可用"提示，不阻塞其余功能 | 风险预案 §8 |

## 3. 阶段 0 · 资源准备（M0，约 0.5 人日）

> 工程宪法：**后端资源必须先于前端代码准备**。本阶段全部通过 MCP 工具完成，逐项带验证。

### 0.1 开启用户名密码登录
```
manageAppAuth   { "action": "patchLoginStrategy", "patch": { "usernamePassword": true } }
manageAppAuth   { "action": "ensurePublishableKey" }
```
验证：`queryAppAuth { "action": "getLoginConfig" }` → `usernamePassword: true`；记录返回的 publishable key。

### 0.2 配置 Web 安全域名（本地开发）
```
queryEnv           { "action": "domains" }                       # 先查现状
envDomainManagement{ "action": "create", "domains": ["localhost:5173", "127.0.0.1:4173"] }
```
注意：生效约 10 分钟。立即轮询 `queryEnv { "action": "domains" }`，生效前可先做 0.3/0.4。部署完成后再把线上子域名追加进来（见 M6）。

### 0.3 创建集合并建索引
```
writeNoSqlDatabaseStructure { "action": "createCollection", "collectionName": "profiles" }
writeNoSqlDatabaseStructure { "action": "createCollection", "collectionName": "food_records" }
writeNoSqlDatabaseStructure { "action": "createCollection", "collectionName": "dishes" }

writeNoSqlDatabaseStructure {
  "action": "updateCollection", "collectionName": "food_records",
  "updateOptions": { "CreateIndexes": [
    { "IndexName": "userId_1_date_1", "MgoKeySchema": { "MgoIsUnique": false,
      "MgoIndexKeys": [ { "Name": "userId", "Direction": "1" }, { "Name": "date", "Direction": "1" } ] } },
    { "IndexName": "userId_1_mealType_1", "MgoKeySchema": { "MgoIsUnique": false,
      "MgoIndexKeys": [ { "Name": "userId", "Direction": "1" }, { "Name": "mealType", "Direction": "1" } ] } }
  ] }
}
```
验证：`readNoSqlDatabaseStructure { "action": "describeCollection", "collectionName": "food_records" }` → 看到两个索引。

### 0.4 配置安全规则（行级隔离）
```
managePermissions { "action": "updateResourcePermission", "resourceType": "noSqlDatabase",
  "resourceId": "food_records", "permission": "CUSTOM",
  "securityRule": "{\"read\":\"doc._openid == auth.uid\",\"create\":\"auth.uid != null\",\"update\":\"doc._openid == auth.uid\",\"delete\":\"doc._openid == auth.uid\"}" }
```
- `profiles` 用同一条规则。
- `dishes`：`{"read":"auth.uid != null","create":"false","update":"false","delete":"false"}`（全员可读、客户端禁写；种子由管理端写入，不受规则限制）。
- 注意 `create` 不能引用 `doc.*`（文档尚不存在），故只校验已登录。
验证：`queryPermissions { "action": "getResourcePermission", "resourceType": "noSqlDatabase", "resourceId": "food_records" }`。

### 0.5 AI 资源确认（已定案，无付费项）
- 用户已开通**小程序成长计划**，控制台确认：文本模型 `hy3` 已开启且有免费额度；生图模型 `HY-Image-3.0-Plus-4090-Tob-v1.0`（文生图，额度 100,000 次，有效至 2027-02-20）与 `HY-Image-v3.0-I2I-ToB-v1.0.1`（图生图）已开启。
- **约束**：成长计划赠送额度仅能在**小程序 SDK 或云函数**中消耗，Web SDK 浏览器直连不可用 → AI 调用统一走云函数 `ai-proxy`（见 M6）。
- 生图额度远超本项目 v1 需求，记为 P2 增强（为菜库生成真实封面图）；v1 仍用色块+首字印章封面。

### 0.6 写入菜库种子数据
1. 编写 `scripts/seed-dishes.json`：约 100 道家常菜，字段 `{ name, kcal, minutes, tags[], ingredients[], steps[], coverColor }`，标签覆盖 `家常/低卡/高蛋白/快手/素食/暖胃/清爽`（供筛选）。手写 30 道核心 + 按模式批量生成余量。
2. 经 `writeNoSqlDatabaseContent { "action": "insert", "collectionName": "dishes", "documents": [...] }` 分批（每批 ≤ 20 条）写入。
验证：`readNoSqlDatabaseContent { "collectionName": "dishes", "limit": 5 }` 计数 ≈ 100。

## 5. 关键代码要点

### 5.1 CloudBase 初始化（EnvId 显式）
```ts
// src/lib/cloudbase.ts
import cloudbase from '@cloudbase/js-sdk'
const ENV_ID = import.meta.env.VITE_TCB_ENV // weixin1-d1g7tcvq913e540f0
if (!ENV_ID) throw new Error('缺少 VITE_TCB_ENV')
export const app = cloudbase.init({ env: ENV_ID })
export const auth = app.auth({ persistence: 'local' })
export const db = app.database()
```

### 5.2 会话守卫
```ts
const s = await auth.getSession()          // 以 auth-web skill 实际返回结构为准
if (!s || !s.session) render(<AuthScreen />)
```

### 5.3 记录写入（_openid 由 SDK 自动注入）

```ts
await db.collection('food_records').add({
  userId: uid, date: '2026-08-29', mealType: 'lunch',
  name, qty, unit, kcal, note: '', source: 'manual',
  createdAt: Date.now(), updatedAt: Date.now(),
```

### 5.4 AI 调用（云函数中转，消耗成长计划免费额度）
```ts
// 前端 src/lib/ai.ts
const res = await app.callFunction({ name: 'ai-proxy', data: { action: 'recipe', messages: history } })
// res.result = { ok: true, recipe: {...} } 或 { ok: true, text: '...' }
```
```js
// cloudfunctions/ai-proxy/index.js（核心，返回结构以 ai-model-nodejs skill 为准）
```
